# BrandMark

Logo hoa sen kèm tên web "Chép Kinh Online" và khẩu hiệu "Tâm an · Pháp lạc".

- Trong code: `BrandMark` (src/components/brand/LotusLogo.tsx). Người dùng truyền `size` (cỡ logo, mặc định 36) và `light` (true trên nền tối).
- Tên web kiểu `brand-name` (cỡ = 0.62 × size). Khẩu hiệu kiểu `tagline` (cỡ = 0.27 × size), viết hoa, giãn 0.28em.
- Trên nền sáng: tên `brown-800`, khẩu hiệu `gold-700`. Trên nền tối: `brand-on-dark` và `tagline-on-dark`.
- Logo dùng logo `LotusLogo`, không tô lại màu, không kéo méo.
